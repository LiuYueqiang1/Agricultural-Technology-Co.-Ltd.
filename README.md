# 鑫源鼎丰农业科技官网

鑫源鼎丰农业科技有限公司的静态品牌官网，使用 HTML、CSS 与原生 JavaScript 构建，可直接部署到 GitHub Pages。

## 品牌定位

专注保温棉被制造十余年的源头工厂。网站围绕真实、专业、可靠、实惠与长期合作展开，不使用未经确认的产能、排名或企业规模数据。

## 网站内容

- 品牌首页与产品应用场景
- 源头工厂真实概况
- 生产流程
- 产品特点与定制服务
- 雨雪环境应用场景
- 成卷装车与物流说明
- 电话、邮箱、地址及在线留言

## 本地预览

项目为纯静态网站。可以直接打开 `index.html`，也可以在项目目录启动任意静态文件服务器进行预览。

页面中的温室、雨雪和部分产品画面用于表达产品应用或视觉方向，不代表企业自有园区、实际客户案例或第三方检测结果。企业自有车间、仓储和发货素材应优先替换为经确认的真实照片。
